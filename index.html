01

MoveTech

MoveTech is a custom stepper motor driver board built for NEMA 23 motors running at 2.8A per phase. Driven by an ESP32 for Wi-Fi and Bluetooth, it features two driver setups (one integrated, one with external MOSFETs), differential line receivers for encoder feedback, hall sensors for current measurement, and an onboard IMU for motion sensing. To keep the board reliable under heavy load, the layout includes multi-layer power planes and exposed thermal vias for heatsink mounting, alongside controlled impedance routing for the RF traces and differential pairs.

03

ProgrammerBox

ProgrammerBox is a USB-to-serial programming interface designed for flashing and debugging custom embedded boards over USB-C. Built around a dedicated USB-to-UART bridge, the hardware incorporates both an auto-reset circuit (driven by standard DTR/RTS line toggling) and physical Boot/Reset buttons for manual mode control. The board features multiple connector headers to support various pinouts and is housed in a custom 3D-printed enclosure with a laser-cut acrylic lid.

LBB - Microphone Board

The Microphone Board is a hardware platform built to demonstrate and evaluate different microphone technologies on a single PCB. Designed to simplify microphone selection for MCU development boards, it features 5 independent channels, three PDM microphones, one I2S microphone, and one analog microphone. The board supports multiple power inputs, including USB-C, benchtop supplies, and power profiler kits (such as a Nordic PPK2), and offers physical switches and jumpers to enable individual channels and swap left/right stereo routing.

RoleSchematic, Layout, BOM, TestingToolsAltium Designer, Saturn PCB Toolkit, Home labFocusSensitive analog signals, Signal voltage levels, Industry standard pinouts, Channel switching logic

05

Flight Controller

STM32F405 Flight Controller is a custom hardware design project built to explore end-to-end embedded development. Powered by an STM32F405 microcontroller and an LSM6DSV16XTR IMU, carefully centered on the PCB to optimize tracking accuracy, the board includes four motor outputs for external ESCs, an SWD programming port, and a UART interface for RF telemetry. Created entirely as a self-directed hobby project, it is supposed to run on BetaFlight open source software so the design is fully open source as well.
